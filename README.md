# Dr. Aasheesh Raturi - GitHub Pages Website

This folder contains a clean, responsive, static website prepared for GitHub Pages using the updated CV information.

## Included files

- `index.html` - full website content
- `styles.css` - colour theme, layout and responsive design
- `script.js` - mobile menu, active links, back-to-top button and publication search
- `assets/profile-aasheesh-raturi.png` - profile photograph extracted from the provided CV
- `assets/science-illustration.svg` - custom research-themed illustration
- `.nojekyll` - helps GitHub Pages publish static assets correctly

## Upload to GitHub

1. Unzip this folder.
2. Open your GitHub repository.
3. Click **Add file > Upload files**.
4. Select all files inside this folder, including the `assets` folder.
5. Commit the changes.
6. Go to **Settings > Pages**.
7. Select **Deploy from a branch**, choose `main` and `/root`, then save.

## Important

Do not upload the folder itself as a nested folder. The repository root should directly show:

- `index.html`
- `styles.css`
- `script.js`
- `README.md`
- `.nojekyll`
- `assets/`

The website intentionally uses professional contact emails and ORCID only. Personal home address, date of birth and private reference details from the CV were not included for public safety.
