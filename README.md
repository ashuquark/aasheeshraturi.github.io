# Dr. Aasheesh Raturi – GitHub Pages Website

This folder contains a clean static version of the personal website for GitHub Pages.

## Files

- `index.html` – complete one-page academic portfolio website
- `styles.css` – responsive design and styling
- `.nojekyll` – tells GitHub Pages to publish the static files directly

## How to publish on GitHub Pages

1. Sign in to GitHub.
2. Create a new public repository named exactly:
   `aasheeshraturi.github.io`
3. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
   - `.nojekyll`
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
6. Save. The website should publish at:
   `https://aasheeshraturi.github.io`
